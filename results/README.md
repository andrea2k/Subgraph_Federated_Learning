# Experiment results

- [paper_results.csv](paper_results.csv): thesis AC Macro PR-AUC summary with final method names, means, and sample standard deviations. It is a fixed snapshot of `results/generated/tables/paper_results.csv`.
- `runs/`: new training outputs, grouped by benchmark, method, q, and seed.
- `generated/`: rebuilt tables, statistics, plot data, communication calculations, and reporting logs.

Training and generated outputs stay local. Thesis and appendix PDFs are included under [figures/](../figures/). See [reproduction](../docs/reproduction.md) for commands and analysis inputs.
